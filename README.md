One satirical sentence roasting lawmakers who would regulate AI, crypto, or the
internet but cannot convert a file to PDF — written by `main.ts` to
`/output/entry.txt` for the [make.fun](https://make.fun) competition
"The Long Roast: Lawmakers and the File They Cannot Convert".

## The line

> The committee that voted to regulate artificial intelligence adjourned early so an intern could teach them to save their own bill as a PDF.

The setup grants the lawmakers their full authority — a committee vote to
regulate artificial intelligence — and the turn undercuts it with the one file
they cannot convert: their own bill, which only an intern can teach them to
save as a PDF. The punch lands on the last words.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is). Writes exactly one line
to `/output/entry.txt` (1–320 characters, UTF-8, a single sentence).
